     |      Batch-attach a tag to multiple memories in a single reducer call.

     |      memory IDs in one call to the ``batch_tag_memories`` reducer.
     |      
     |      Args:

     |      
     |      Args:
     |          tag_id: The tag to detach.
     |          memory_ids: List of memory ID strings to untag. Missing
