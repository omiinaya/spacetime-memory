### 1.1 ClientBase (`_base.py`)
- **Connection**: HTTP client to SpacetimeDB (configurable host/port/secure)
- **Auth**: JWT token auth, identity token capture
- **Error types**: `SpacetimeDBError`, `NotFoundError`, `ApiError`, `EmbedderUnavailableError`
- **Logging**: `configure_logging(level, json_format, log_file)`, `JSONFormatter`
- **SQL helpers**: `_call()` (reducers), `_query()` (table reads), `_sql()` (raw SQL), `_sql_param()` (parametrized SQL)
- **Error maps**: SQL error map (table not found, duplicate key, syntax, permission) + reducer error map (not found, unauthorized, rate limit)
- **Plugin dispatch**: `plugin_manager` protocol integration
- **Query cache**: LRU query cache integration
- **Event bus**: `_emit_event()` for streaming events
- **Metrics collector**: endpoint latency/error tracking
- **Health**: `_request_with_retry_simple()`, embedder health alerts

## 2. COMPOUNDER (`compounder/`)

The `Compounder` class composes `CompounderWorkflows` (5 workflow mixins) + `CompounderHelpers`:

```python
Compounder(CompounderWorkflows, CompounderHelpers)
```

### 2.1 Search Workflows (`workflows_search.py`)
- `search_entities(workspace_id, label?, node_type?, semantic_query?, limit)` — flexible KG entity search

### 2.2 Knowledge Base Workflows (`workflows_knowledge.py`)
- `store_answer(query, answer, workspace_id, source_memory_ids?, title?, embed, skip_duplicates, duplicate_threshold)` — persist LLM synthesis as note + KG nodes
- `create_entity_page(name, description, workspace_id, node_type, source_memory_ids, embed)` — structured entity wiki page + KG node
- `update_entity_page(name, description, workspace_id)` — update entity page
- `create_concept_page(concept, definition, workspace_id, source_memory_ids, embed)` — concept definition with wiki-links
- `create_comparison_page(title, items, workspace_id, source_memory_ids, embed)` — markdown comparison table
- `ingest_source(workspace_id, title, content, source_type, source_path, auto_cross_ref, auto_contradiction_check)` — full source ingestion pipeline
- `lint_workspace(workspace_id, llm_check, with_llm)` — health check: orphans, missing cross-refs, contradictions
- `generate_overview_page(workspace_id)` — generate _overview with stats, entities, activity

### 2.3 Graph Workflows (`workflows_graph.py`)
- `cross_link(workspace_id, limit, similarity_threshold)` — auto-link semantically related but unconnected memories/nodes
- `suggest_connections(workspace_id, limit)` — find node pairs sharing neighbors without direct link

### 2.4 Ripple Workflows (`workflows_ripple.py`)
- `detect_ripple_effects(source_id, workspace_id, max_hops, include_notes, stale_only)` — walk KG to find entities needing re-summarization

### 2.5 Export Workflows (`workflows_export.py`)
- `export_workspace(output_dir, workspace_id, include_kg, include_system_notes, kg_json)` — export notes as markdown files with YAML frontmatter (Obsidian-ready) + optional KG JSON export

## 3. TOP-LEVEL MODULES

### 3.1 LLM Client (`llm.py`)
- OpenAI-compatible chat completion client
- Methods: `generate()`, `summarize()`, `classify()`, `extract_entities()`, `embed()`
- Configurable via env vars: `OPENAI_API_KEY`, `OPENAI_BASE_URL`, `LLM_MODEL`
- Graceful degradation when no API key

### 3.2 Local LLM (`local_llm.py`)
- GGUF local model support via llama-cpp-python
- `LocalLLM(model_path)` / `LocalLLM.auto()` — auto-discover model
- Methods: `summarize()`, `generate()`, `embed()`
- Recommended models: MiniCPM5-1B

### 3.3 Veracity (`veracity.py`)
- 5-tier VeracityTier enum: STATED, UNKNOWN, INFERRED, IMPORTED, TOOL
- Bayesian confidence compounding: `compound(tier, sources)` = 1 - (1-base)^n
- `confidence_multiplier(confidence)` — 0.0-2.0 range for search scoring
- `detect_tier(source, extraction)` — auto-detect tier from source type
- Default base confidences: STATED=1.0, UNKNOWN=0.5, INFERRED=0.7, IMPORTED=0.6, TOOL=0.9

### 3.4 Binary Vectors (`binary_vectors.py`)
- MIB (Maximally Informative Binarization) sign-based binarization
- `binarize(embedding)` — float32[] → bytes (32× compression)
- `hamming_similarity(a, b)` — bitwise XOR + popcount, [0.0, 1.0]
- `hamming_distance(a, b)`
- `batch_hamming_similarities(query, candidates)`

### 3.5 Entity Linking (`entity_linking.py`)
- LLM-based entity extraction + KG node creation
- `link_entities(client, workspace_id, source_text, source_memory_id, source_document_id)` — full pipeline
- `extract_entities_llm(client, text)` — LLM extraction
- `inject_entity_context(query, entities, max_entities)` — context injection
- `find_entities_in_query(query, entities)` — query entity matching
- Fallback: regex-based extraction (tech terms, companies, acronyms)

### 3.6 Cross-Encoder (`cross_encoder.py`)
- ONNX cross-encoder reranker (ms-marco-MiniLM-L-6-v2)
- Zero PyTorch dependency (tokenizers + onnxruntime)
- GPU auto-detection: CUDA → ROCm → CPU
- `CrossEncoderReranker.rerank(query, candidates)` — relevance re-scoring
- Configurable via `CROSS_ENCODER_PROVIDER` env var

### 3.7 MMR Reranking (`mmr.py`)
- Maximal Marginal Relevance reranking (Carbonell & Goldstein 1998)
- `mmr_rerank(results, query, lambda_param, top_k)` — balance relevance + diversity
- Uses Jaccard similarity for content comparison

### 3.8 Weibull Temporal Boost (`weibull.py`)
- `weibull_weight(age_seconds, k, lam, floor)` — recency weighting via Weibull survival
- Default: k=0.5 (rapid initial decay, long tail), lam=7 days, floor=5%

### 3.9 Query Cache (`query_cache.py`)
- Thread-safe LRU cache for search results
- Configurable maxsize (default 128) and TTL (default 300s)
- `make_key()`, `get()`, `set()`, `invalidate(workspace_id)`, `clear()`

### 3.10 Query Expansion (`query_expansion.py`)
- LLM-based query expansion with synonyms/related terms
- `expand_query(query, endpoint?, model?, api_key?, timeout?)` → expanded string
- Uses same endpoint as reranker (env vars: `LLM_RERANK_ENDPOINT`, `LLM_RERANK_MODEL`, `LLM_RERANK_API_KEY`)

### 3.11 Streaming Events (`streaming.py`)
- `EventBus` — typed event subscription/dispatch
- `MemoryEvent` dataclass (event_type, data, timestamp, event_id, workspace_id)
- Events: memory.created, memory.updated, memory.deleted, search.performed
- Thread-safe pub/sub

### 3.12 WebSocket Subscription (`ws_subscription.py`)
- `WsSubscription` — real-time push notifications via WebSocket
- `ManagedSubscription` — auto-reconnecting subscription
- `SubscriptionManager` — manage multiple subscriptions
- `ChangeEvent` — change event dataclass (table, operation, data)
- Callbacks per (table, operation) pairs

### 3.13 Delta Sync (`delta_sync.py`)
- `DeltaSync` — polling-based change detection on `change_event` table
- Configurable poll interval (default 100ms)
- Callbacks per (table, operation) with subscribe/unsubscribe tokens
- Background polling thread

### 3.14 Plugin Manager (`plugin_manager.py`)
- `PluginManager` — registry + lifecycle hooks
- `BasePlugin` — abstract base with hooks: `on_store()`, `on_search()`, `on_consolidate()`, `on_export()`, `on_import()`
- Built-in hooks for data transformation, filtering, enrichment

### 3.15 Tracer (`tracer.py`)
- OpenTelemetry integration with OTLP HTTP export
- `Tracer(service_name)` — setup OpenTelemetry
- `get_tracer(setup)` / `start_span(name, attributes)` — decorator/context manager
- Configurable via env vars: `OTEL_EXPORTER_OTLP_ENDPOINT`, `OTEL_SERVICE_NAME`, `OTEL_ENABLED`, `OTEL_SAMPLING_RATIO`

### 3.16 Auth (`auth.py`)
- ES256 (ECDSA P-256) JWT token generation for SpacetimeDB auth
- `generate_token(private_key_path, key_id?)` — supports key rotation via `kid` header

### 3.17 Context Agent (`context_agent.py`)
- `ContextAgent` — query → context pack → LLM-synthesised answer
- `ask(query, workspace_id, memory_limit, use_llm)` — grounded Q&A with citations
- `get_context(query, workspace_id, limit)` — raw context pack

### 3.18 Ingest (`ingest.py`)
- `CodebaseIngester` — tree-sitter-based code ingestion
- Walks source tree, creates KG nodes for files/functions/classes/methods
- Creates edges: imports, calls, inherits
- Supports Python, JavaScript, TypeScript, Rust, Go, and more via tree-sitter-language-pack

### 3.19 SHMR (`shmr.py`)
- Self-Harmonizing Memory Reasoning engine
- Clusters memories by embedding similarity
- LLM harmonization of contradictions into stable beliefs
- Harmony score computation
- Stores beliefs via reducers

### 3.20 Agent Orchestrator (`agent_orchestrator/`)
- `AgentOrchestrator(SessionManagerMixin, StepRecordingMixin)`
- Session lifecycle management
- Step recording (thought/action/observation/tool_call/tool_result)
- Tool-use tracking
- Multi-user collaboration support

### 3.21 Metrics (`metrics/`)
- `MetricsCollector` — endpoint latency/error/recovery stats
- `EndpointStats` — per-endpoint counters (count, errors, latency min/max/avg)
- `MemoryStats` — memory usage tracking
- OpenTelemetry bridge: `setup_otel_metrics()`, `collect_otel_metrics()`, `remove_otel_metric_readers()`, `is_otel_metrics_active()`

### 3.22 Protocols (`_protocols.py`)
- Runtime-checkable protocols for dependency injection:
  - `PluginManagerProtocol` (dispatch_store, dispatch_search, dispatch_export, dispatch_import)
  - `EventBusProtocol` (subscribe, unsubscribe, emit)
  - `LocalLLMProtocol` (generate, embed, available)
  - `MetricsCollectorProtocol` (record, report, reset)
  - `QueryCacheProtocol` (get, set, invalidate, clear)
